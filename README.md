📊 Madhav Ecommerce Sales Dashboard
📌 Overview

This project is an interactive e-commerce sales dashboard built using Power BI to analyze sales performance, profitability, product categories, customers, payment methods, and geographical trends.

The dashboard provides a consolidated view of key business metrics and allows users to interactively analyze sales data using quarter and state filters.

🎯 Key Metrics

The dashboard tracks important e-commerce KPIs including:

Total Sales Amount: 118K
Total Profit: 12K
Average Order Value: 33K
Total Quantity Sold: 1,409
📊 Dashboard Insights

The dashboard includes visualizations for:

💰 Profit Analysis
Profit by month
Monthly profit trends across October, November, and December
Profit comparison across different states
📦 Product Analysis
Quantity sold by product category
Profit by product/product type
Identification of high-performing product categories
👥 Customer Analysis
Sales amount by customer
Comparison of sales contribution across individual customers
💳 Payment Analysis
Quantity distribution across different payment methods
Comparison of customer transaction preferences
🌎 Geographic Analysis
State-wise sales/profit analysis
Interactive state-level filtering
🎛️ Interactive Features

The dashboard provides interactive filters for:

Quarter
State

These filters allow users to dynamically explore sales and profitability across different time periods and geographical regions.

🚀 How to Use
Install Power BI Desktop.
Download the .pbix dashboard file.
Open the file using Power BI Desktop.
Use the Quarter and State filters to explore the data.
Interact with the visualizations to analyze sales and profitability.
